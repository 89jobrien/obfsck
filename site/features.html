Features

Cargo features exactly as declared in Cargo.toml. The Enables column lists the optional dependencies a feature pulls in, so a dash there means only that the feature enables no extra crates — not that nothing reads it. The Gates column says what each feature actually changes in the code.

path-policy-home-user-redact and path-policy-non-allowlisted-redact are mutually exclusive. Enabling both is a compile error, not a silent precedence rule.

analyzer is a required-features gate on all six binaries. Building with --no-default-features produces a library with no executables at all.
