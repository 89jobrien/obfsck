obfsck Overview Guide Crates Features CLI Commands

CLI

Every block below is the real --help output, captured by scripts/gen_cli_help.py. It is a transcription, so it can drift; re-run that script after upgrading or changing any flag. Use --check in CI to catch a stale page.

Canonical commands

obfsck is the supported entry point. The standalone redact, analyzer, and scan binaries still exist for compatibility but warn on every run.

obfsck --help

obfsck --help
$ Redact and analyze sensitive log data

Usage: obfsck <COMMAND>

Commands:
  redact   Redact secrets and PII from a file or stdin
  analyze  Fetch and analyze security alerts
  scan     Scan a diff for secrets using obfsck and gitleaks
  help     Print this message or the help of the given subcommand(s)

Options:
  -h, --help     Print help
  -V, --version  Print version

obfsck redact --help

obfsck redact --help
$ Redact secrets and PII from a file or stdin

Usage: obfsck redact [OPTIONS] [INPUT]

Arguments:
  [INPUT]  Input file to redact. Reads from stdin if omitted

Options:
  -o, --output <OUTPUT>        Write redacted output to this file instead of stdout
  -l, --level <LEVEL>          Obfuscation level: minimal, standard, paranoid [default: minimal]
  -c, --config <CONFIG>        Path to secrets YAML config. Lookup order: explicit path → ~/.config/obfsck/secrets.yaml → bundled config
      --audit                  Print a per-pattern match report to stderr. Output is still written to stdout
      --profile <PROFILE>      Preset profile: default, pii, full, paranoid [default: default]
      --pii <PII>              Enable or disable PII redaction (email, IP, names, SSN, etc.). Secrets (API keys, tokens) are always redacted regardless of this flag. Accepted values: on, off, true, false, yes, no, 1, 0 [default: on]
      --allowlist <VALUE>      Values to never redact, even if they match a pattern. Repeatable. Also loaded from ~/.config/obfsck/allowlist (one entry per line)
      --allowlist-file <PATH>  File containing allowlist entries, one per line
  -h, --help                   Print help
  -V, --version                Print version

obfsck analyze --help

obfsck analyze --help
$ Fetch and analyze security alerts

Usage: obfsck analyze [OPTIONS]

Options:
  -c, --config <CONFIG>
          Path to analyzer config YAML. Lookup order: explicit path → ~/.config/obfsck/analyzer.yaml → bundled config
  -p, --priority <PRIORITY>
          Only analyze alerts with this priority, e.g. high or critical
  -l, --last <LAST>
          How far back to fetch alerts, as a duration such as 1h or 24h [default: 1h]
  -n, --limit <LIMIT>
          Maximum number of alerts to fetch and analyze [default: 5]
  -d, --dry-run
          Build and print the LLM prompt without calling the API
  -s, --store
          Persist successful analyses to the result cache. Ignored with --dry-run
  -v, --verbose
          Log the obfuscation token summary for each analyzed alert
  -j, --json
          Emit results as JSON instead of rendered text
      --loki-url <LOKI_URL>
          Override the Loki URL. Implies the loki backend
      --victorialogs-url <VICTORIALOGS_URL>
          Override the VictoriaLogs URL. Implies the victorialogs backend
  -b, --backend <BACKEND>
          Log backend to query: loki or victorialogs
  -h, --help
          Print help
  -V, --version
          Print version

obfsck scan --help

obfsck scan --help
$ Scan a diff for secrets using obfsck and gitleaks

Usage: obfsck scan [OPTIONS]

Options:
      --staged            Run `git diff --staged` internally instead of reading from stdin
  -l, --level <LEVEL>     Obfuscation level for obfsck patterns: minimal, standard, paranoid [default: minimal]
      --no-gitleaks       Skip the gitleaks scan even if gitleaks is on PATH
      --require-gitleaks  Treat a missing gitleaks binary as an error (default: skip silently)
  -h, --help              Print help
  -V, --version           Print version

scan --help

scan --help
$ Scan a unified diff for secrets using obfsck patterns and gitleaks.

Reads the diff from stdin, or captures `git diff --staged` when `--staged` is passed. Exits 0 when clean, 1 when findings are reported, and 2 when the scanner itself cannot run.

Usage: scan [OPTIONS]

Options:
      --staged
          Run `git diff --staged` internally instead of reading from stdin

  -l, --level <LEVEL>
          Obfuscation level for obfsck patterns: minimal, standard, paranoid
          
          [default: minimal]

      --no-gitleaks
          Skip the gitleaks scan even if gitleaks is on PATH

      --require-gitleaks
          Treat a missing gitleaks binary as an error (default: skip silently)

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version

Other binaries

obfsck-mcp reads JSON-RPC from stdin and does not use clap, so it has no --help. It supports --version. See the guide for the tool surface.
